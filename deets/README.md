# GraveFinder – Cemetery Management and Grave Search System

## About the System

**GraveFinder** is a web-based cemetery management and grave search system developed as a Capstone Project. The system is designed to provide a more organized and accessible way of managing cemetery records while helping visitors search for deceased individuals and access available burial information.

The project aims to reduce the difficulty of manually searching through cemetery records by providing a centralized digital platform for grave and burial information.

GraveFinder consists of two primary areas: the **Visitor Panel** and the **Administrator Panel**.

The Visitor Panel allows users to search and browse available cemetery records, while the Administrator Panel is intended for authorized personnel responsible for maintaining and managing system information.

## System Features

### Visitor Panel

The Visitor Panel provides public access to available cemetery information.

The module is designed to support the following functions:

* Search for deceased individuals
* View burial and grave information
* Browse available cemetery records
* Access cemetery information through a simple interface

### Administrator Panel

The Administrator Panel is intended for authorized cemetery personnel and system administrators.

The module is designed to support:

* Adding deceased and grave records
* Editing existing cemetery information
* Deleting records when necessary
* Managing visitor-accessible information
* Maintaining cemetery database records
* Monitoring and organizing system data
