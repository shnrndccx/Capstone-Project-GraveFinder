# Capstone Project - GraveFinder

## Overview

GraveFinder is a web-based cemetery management and grave search system designed to help visitors locate graves and access burial information efficiently. The system provides an organized database of records while allowing administrators to manage cemetery data through a dedicated administration panel.

## Features

### Visitor Panel

* Search for deceased individuals
* View burial information
* Browse available records
* User-friendly interface

### Admin Panel

* Manage deceased records
* Add, edit, and delete grave information
* Manage visitor-accessible data
* Maintain cemetery database records

## Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL

## System Modules

### Visitor Module

Provides public access to cemetery records and search functionality.

### Administrator Module

Allows authorized personnel to manage cemetery information and maintain database accuracy.

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sca-xx/Capstone-Project-GraveFinder.git
   ```

2. Move the project to your local server directory.

3. Import the database file into MySQL.

4. Configure the database connection settings.

5. Start your local server and access the application through your browser.

## Project Purpose

The goal of GraveFinder is to improve cemetery record management and simplify the process of locating graves through a centralized digital system.
